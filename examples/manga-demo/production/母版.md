# Demo 动态漫 · 制作母版（林可排错样板 v0.1）

> 本样板用于沉淀 AI 编程类竖屏动态漫的可复用流水线，后续剧集沿用同一角色锁、分镜结构、合成与上线流程批量生成。
> 成片：`website/static/videos/demo-lin-ke.mp4`；页面：`docs/manga/episodes/demo-lin-ke-bug/index.md`。

## 一、总体参数

| 项 | 值 |
| --- | --- |
| 画幅 | 竖屏 9:16，720×1280，H.264 mp4 + AAC |
| 分段 | 4 段，每段 5 秒（实际 5.0417s），硬切拼接，成片 20.25s |
| 首帧生成 | image_gen，seedream_5.0_pro，9:16（输出 1536×2730，站点用帧缩放 720×1280 JPEG） |

## 四、动态 Prompt 要点（每段通用）

- 真人自然肢体与表情：呼吸、眨眼、转头、手势、肩部与上身微动；禁止静帧缓慢推镜。
- 镜头固定或平缓有目的，不抖动、不跳切；屏幕内容为真实编辑器 / 控制台界面，文字模糊可辨即可。
- 一致性禁区：发型、服装、场景在 4 段间不得变化；不新增人物；不出现漫画式图形与悬浮机器人实体。

## 五、素材与合成

1. 首帧本地副本：`frames/01.png … 04.png`（gitignore；CDN 短期链接可能过期，以本地为准）。
2. 片段下载到 `segments/seg01.mp4 … seg04.mp4`（gitignore），720×1280、HEVC、yuv420p、AAC 44.1kHz。
3. 配音：`production/voice/seg01.mp3 … seg04.mp3`；合成时 `adelay` 对齐 600 / 5642 / 10683 / 15725 ms，`amix` 混合为配音轨，丢弃片段原生音轨。
4. 字幕：`production/subtitles.ass`（gitignore）；`subtitles.json` 为入库字幕时间轴资产。
5. 合成输出：`libx264 -preset medium -crf 20 -pix_fmt yuv420p -c:a aac -b:a 128k`，成片复制到 `website/static/videos/demo-lin-ke.mp4`。

## 六、已知偏差与待办

- 屏幕代码气泡为模型生成的示意伪代码，非可编译真实代码；样板演示可接受，正式教程剧集应让屏幕内容对应真实源码片段。
- 配音轨经 amix 后为单声道；收听无影响，如需立体声可在合成 filter 中补 `aformat=channel_layouts=stereo`。
- 无 BGM（与 EP01 一致）；如需轻快低音量科技轻音乐，在后期混入独立音轨，不写入视频生成 prompt。
- 后续如有声音克隆能力，可将 XiaoxiaoNeural 替换为林可克隆音色，人设描述与台词不变。
