# EP01 动态漫 · 制作母版 v02（真人写实版）

> v01 为扁平国漫风；v02 按反馈改为真人实拍风、动作自然化、剧情加入情绪节拍。
> 声音维持现状：片段仅原生环境音，无对白配音、无 BGM，台词由后期字幕承载。

## 一、总体参数

| 项 | 值 |
| --- | --- |
| 画幅 | 竖屏 9:16，720×1280，H.264 mp4 |
| 分段 | 7 段，每段 5 秒，硬切拼接 |
| 首帧生成 | image_gen（seedream），7 张真人写实帧 |
| 动态模型 | image_to_video，**seedance_2.5**（动作自然度优于 fast），duration 5，ratio 9:16 |
| 后期 | MediaKit editing：concat-video 拼接 → add-subtitle-to-video 压制字幕 |
| 字幕 | subtitles.json，12 条，lower_third，38px，思源黑体白色 |

## 二、人物与场景锁定（跨帧必须一致）

- **阿乐**：二十多岁中国年轻男生，黑色短发微乱，浅蓝休闲卫衣，深色长裤；表情生动，新手。
- **文哥**：三十多岁中国男性，利落短发，细框眼镜，浅灰简约衬衫，沉稳；**不戴安全帽**。
- **场景**：现代简约居家书房 / 联合办公，木质书桌，笔记本电脑、机械键盘、咖啡杯、台灯；暖色屏幕光叠加环境自然光，浅景深，真实皮肤与面料质感，35mm 写实摄影，电影感竖屏。
- **AI 助手**：写实呈现为编辑器侧边 AI 面板（蓝色光晕、代码气泡），**不做悬浮机器人实体**，避免与真人实景违和。
- 两人为虚构普通人物，不对应任何真实名人。

## 三、分镜与动作节拍（情绪：迷茫 → 陪伴 → 恍然 → 惊喜 → 兴奋 → 受挫 → 安抚 → 成功）

| 段 | 时间 | 画面与动作 | 镜头 | 情绪 |
| --- | --- | --- | --- | --- |
| SEG01 | 0–5s | 阿乐独自对空白屏幕皱眉抓头发；文哥端咖啡从右侧走入，拉椅坐下，轻拍阿乐肩膀，阿乐抬头 | 中景缓慢推近；自然呼吸、转头、拍肩手势 | 迷茫 → 被陪伴 |
| SEG02 | 5–10s | 文哥侧身指向笔记本屏幕（Spring 项目结构/依赖），阿乐凑近，由皱眉转点头；文哥手指屏幕讲解，另一手摊开 | 过肩中景；手指动作 + 表情变化 | 恍然 |
| SEG03 | 10–15s | 编辑器侧边 AI 面板代码逐行生成流动；阿乐眼睛睁大、嘴角上扬，转头看向文哥，文哥微笑点头 | 近景阿乐表情 + 屏幕反光 | 惊喜 |
| SEG04 | 15–20s | 终端创建 React 项目，文件列表/进度条展开；阿乐双手离键盘，握拳小兴奋，肩膀放松 | 中景；手部键盘 + 上半身动作 | 兴奋 |
| SEG05 | 20–25s | 浏览器控制台红色跨域报错；阿乐后仰靠椅背、皱眉摊手；文哥镇定抬手，手指报错位置，安抚点头 | 屏幕特写切双人中景 | 受挫 → 被安抚 |
| SEG06 | 25–30s | 浏览器页面成功加载数据卡片；两人对视微笑，同时竖拇指；阿乐轻拍桌沿 | 中景双人；屏幕暖光映脸 | 成功 |
| SEG07 | 30–35s | 写实桌面收束：笔记本、咖啡、便签；镜头缓慢横移，知识点由字幕卡片叠加，不出现漫画式图形 | 缓慢横移近景 | 收束 |

## 四、动态 Prompt 要点（每段通用）

- 真人自然肢体与表情：呼吸、眨眼、转头、手势、肩部与上身微动；禁止静帧缓慢推镜。
- 镜头运动平缓有目的（推近 / 过肩 / 横移），不抖动、不跳切。
- 屏幕内容为真实编辑器 / 终端 / 浏览器界面，文字模糊可辨即可，不追求可读代码。
- 一致性禁区：人物发型、服装、眼镜、场景在 7 段间不得变化；不新增人物；不出现安全帽。
