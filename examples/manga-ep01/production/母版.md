## 成片参数

| 项 | 值 |
| --- | --- |
| 成片数量 | 1 条 |
| 画幅 | 9:16 竖屏 |
| 视频模型 | seedance 2.0 fast（`seedance_2.0_fast`） |
| 分段 | 7 段，每段 5 秒；拼接后成片 35 秒 |
| 帧图规格 | 540 × 960，9:16 |
| 声音 | 片段仅轻微室内环境氛围音，无对白旁白；台词由字幕呈现；不后期叠加配音与 BGM |
| 字幕 | 后期 editing 域 `add-subtitle-to-video` 压制，9:16 下三分之一安全区 |
| 风格 | 扁平国漫科普漫剧，干净黑色线条，低饱和柔和配色，白底，画面简洁，无大段文字，人物比例正常无畸变 |

## 角色锁定（跨 7 帧保持一致）

- **阿乐**：短发少年，浅蓝休闲卫衣，表情丰富，常带疑惑或恍然大悟。
- **文哥**：简约浅灰衬衫，沉稳耐心的资深全栈工程师，习惯手指屏幕讲解。
- **AI 助手**：半透明蓝色悬浮机器人，带柔和蓝光，旁边浮现代码片段气泡。

## 分镜与片段（SEG01–SEG07）

### SEG01（0–5s）· 书桌前的困惑
- 画面：阿乐对着空白文件夹挠头，电脑屏幕空空；文哥从画面侧边出现。
- 字幕
  - 0.3–2.4s｜阿乐：我想做一套前后端项目，不知道从哪里下手……
  - 2.7–4.7s｜文哥：别慌，我们一步一步从零搭建。
- 视频 Prompt 要点：以首帧为基准，镜头缓慢轻推；阿乐挠头皱眉，文哥侧身走近；保持角色外形与画风；轻微室内环境氛围音；无对白。

### SEG02（5–10s）· 后端初始化
- 画面：IDE 中 Spring Initializr 界面，文哥指向屏幕，阿乐在旁观察。
- 字幕
  - 5.3–7.6s｜文哥：后端先用 Spring Boot，引入 Web、MyBatis、MySQL 依赖。
  - 7.9–9.7s｜阿乐：原来不是自己手写所有文件！
- 视频 Prompt 要点：首帧基准；文哥手指屏幕，界面选项轻微高亮；镜头小幅横移；阿乐点头；无对白。

### SEG03（10–15s）· AI 辅助开发
- 画面：蓝色半透明 AI 助手悬浮 IDE 侧边，周围浮现代码片段气泡；文哥与阿乐看屏幕。
- 字幕
  - 10.3–12.8s｜文哥：Cursor、Cloud Code 这类 AI 工具可以帮我们生成基础配置与实体类。
  - 13.1–14.7s｜阿乐：哇，AI 直接帮我写实体和样板代码？
- 视频 Prompt 要点：首帧基准；AI 机器人悬浮轻晃，代码气泡缓慢上浮；柔和蓝光呼吸感；两人看向侧边；无对白。

### SEG04（15–20s）· 前端初始化
- 画面：VS Code 与终端窗口，终端显示创建 Vite React 项目命令行；文哥指向终端，阿乐点头。
- 字幕
  - 15.3–17.4s｜文哥：前端用 Vite 创建 React 项目，比老的脚手架更快。
  - 17.7–19.7s｜阿乐：前后端是分成两个项目存放吗？
- 视频 Prompt 要点：首帧基准；终端行轻微滚动感；文哥指向终端；镜头缓慢轻推；无对白。

### SEG05（20–25s）· 跨域报错
- 画面：浏览器控制台红色报错提示块，阿乐惊讶皱眉，文哥在旁准备解释。
- 字幕
  - 20.3–22.3s｜阿乐：接口访问失败！这个跨域报错是什么？
  - 22.6–24.7s｜文哥：这是新手最高频的坑，后端加一段 CORS 跨域配置就能解决。
- 视频 Prompt 要点：首帧基准；红色报错块轻微闪烁；阿乐前倾惊讶，文哥抬手解释；镜头固定；无对白。

### SEG06（25–30s）· 前后端打通
- 画面：浏览器页面成功展示后端返回的数据卡片，阿乐与文哥微笑竖拇指。
- 字幕
  - 25.3–27.3s｜文哥：前后端打通！接下来我们学习 MyBatis 数据库操作。
  - 27.6–29.6s｜阿乐：期待下一集 MyBatis！
- 视频 Prompt 要点：首帧基准；页面数据卡片淡入；两人微笑竖拇指；镜头缓慢轻拉收束；明亮积极；无对白。

### SEG07（30–35s）· 知识点卡片
- 画面：圆角知识卡片，标题“本集核心要点”，四个图标条目：Spring Boot、React、AI 编码、CORS 跨域。
- 字幕：画面内文字承担要点；无对白字幕。
- 视频 Prompt 要点：首帧基准；卡片四个条目依次轻微高亮；静帧缓慢缩放运镜；收束定格。

## 后期流程

1. 7 段图生视频片段按 SEG01–SEG07 顺序 `concat-video` 拼接（轻转场）。
2. `add-subtitle-to-video` 按 `subtitles.json` 压制字幕。
3. 成片输出 `website/static/videos/ep01.mp4`，页面 `<video>` 嵌入。

## 一致性与禁区

- 7 帧与 7 段保持阿乐、文哥、AI 助手同一外形与配色；不新增角色。
- 画面内不出现大段代码或长文字；技术界面用抽象色块与图标表达。
- 不生成逐句对白口型；不出现水印、平台角标、乱码文字。
