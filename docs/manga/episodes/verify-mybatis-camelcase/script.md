## 剧情结构

1. **冲突**：林可写 MyBatis 查询，SQL 执行成功却查不到数据，皱眉求助旁边的文哥。
2. **求助**：文哥俯身一起看代码，提示核对数据库字段与实体类属性名是否对上。
3. **解决**：屏幕特写 XML 映射，发现下划线与驼峰命名不一致、未开启自动转换；林可恍然大悟。
4. **收尾**：林可改完配置，与文哥对视微笑；文哥补充 MyBatis-Plus 可一键开启驼峰转换。
