双人小样 · MyBatis 踩坑：为什么查不到数据？

🎬 本页为双人知识教程验证小样：固定女主林可 + 固定男工程师文哥；半写实插画分镜，台词走旁白画外音、人物不开口；代码特写为本地渲染的真实代码卡片，角色以圆角小窗配名牌出镜，规避 AI 假屏幕与口型错位。

🎬 动态漫视频（竖屏 9:16，约 20 秒）​

林可：奇怪，SQL 执行成功，怎么查不到数据？

文哥：你看看数据库字段和实体类属性名，是不是没对上？

林可：哦！下划线和驼峰没开启自动转换！

文哥：MyBatis-Plus 可以一键开启这个配置。

小样要点​

  • ✅ 旁白驱动：台词为画外音，人物不开口，从范式上规避口型与音画错位
  • ✅ 真实代码画面：本地渲染 IDE 风格代码卡片，代码取自仓库真实 MyBatis 源码，无 AI 乱码
  • ✅ 双角色专属配音：林可 XiaoxiaoNeural，文哥 YunyangNeural，后期对齐字幕
  • ✅ 空间一致：人物仅固定机位氛围出镜，无走动换位，避免跨镜头瞬移
  • ✅ 漫剧分镜：开场为双人插画全幅分镜 + 林可对白气泡；代码卡段配对应角色半身插画小窗与彩色名牌（林可琥珀 / 文哥蓝灰）
  • ✅ 克制动效：小窗滑入淡入并缓慢推镜；重点行淡入高亮、关键词下划线逐段展开，高亮出现时配轻提示音
  • ✅ 剧情节拍：冲突（查不到数据）→ 求助（核对映射）→ 发现（驼峰未转换）→ 解决（MP 配置）

制作说明​

  • 角色插画按锁定人设由文生图批量生成，跨镜头保持同一张脸、发型与服装一致；代码卡片由本地 HTML + 浏览器渲染，保证代码文字准确可读；
  • 动效由本地帧序列生成：插画推镜、气泡与名牌、高亮淡入与下划线展开均在 PIL/FFmpeg 阶段完成，不引入 AI 视频运动；
  • 配音与字幕在本地后期对齐合成，成片 720×1280、H.264 + AAC、9:16；
  • 不使用文生视频承担人物表演，口型、空间漂移等 AI 视频问题由范式规避。
