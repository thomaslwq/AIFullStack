双角色人设前缀来自 examples/manga-verify-mybatis/character-ref.json，每条生图 prompt 最前面强制拼接；每张帧独立写全 prompt，不写「同上」。

人设锁前缀​

林可（女主）

24 岁中国女生，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；白色修身衬衫，黑色高腰西装短裙，简约黑色低跟鞋；专业程序员气质，不浮夸；脸部特征全程锁定，同一张脸，发型不变，服装不变，肤色一致。

文哥（男主）

28 岁后端工程师，短发，细框眼镜，浅灰 Polo 衫，气质沉稳耐心；写实真人，同办公室光影；脸部特征全程锁定，同一张脸，发型不变，服装不变，肤色一致。

全局画风后缀​

都市写实摄影，现代互联网办公室，柔和冷暖混合柔光，浅景深，4K 高清，皮肤与面料质感真实，肢体自然，电影感竖屏，9:16。

逐镜生图 Prompt​

镜头 1（冲突 · 双人工位）​

【林可固定人设】24 岁中国女生，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；白色修身衬衫，黑色高腰西装短裙；专业程序员气质。旁边坐着【文哥固定人设】28 岁后端工程师，短发，细框眼镜，浅灰 Polo 衫，气质沉稳耐心。现代互联网办公室工位，两人并排坐在电脑前，电脑打开 IDEA，屏幕是 MyBatis 查询代码；林可眉头微蹙，转头看向旁边的文哥，手指轻点屏幕，一脸疑惑；桌面有咖啡、便签、机械键盘。【全局画风后缀】

镜头 2（求助 · 双人讲解）​

【林可固定人设】24 岁中国女生，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；白色修身衬衫，黑色高腰西装短裙；专业程序员气质。旁边坐着【文哥固定人设】28 岁后端工程师，短发，细框眼镜，浅灰 Polo 衫，气质沉稳耐心。文哥俯身凑近电脑屏幕，手指指向 XML 代码区域，耐心给林可讲解；林可侧头看向屏幕与文哥，两人同框，互动自然。【全局画风后缀】

镜头 3（解决 · 屏幕特写）​

电脑屏幕特写，IDE 打开 MyBatis 映射 XML 文件，column 为下划线命名、property 为驼峰命名，两行命名不一致；画面边缘露出林可的手，她恍然大悟，轻拍桌面；柔和屏幕光映在手上；写实屏幕摄影，浅景深，皮肤与面料质感真实，9:16 竖屏。

镜头 4（收尾 · 双人对视）​

【林可固定人设】24 岁中国女生，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；白色修身衬衫，黑色高腰西装短裙；专业程序员气质。旁边坐着【文哥固定人设】28 岁后端工程师，短发，细框眼镜，浅灰 Polo 衫，气质沉稳耐心。林可敲完代码，抬头看向文哥，轻松微笑，两人对视，氛围轻松；工位背景自然。【全局画风后缀】

视频片段运动提示（image_to_video）​

只写动作、表情、镜头；不写台词、配乐、人声、字幕、时长、比例、模型。

  • 镜头 1：固定机位；林可视线从屏幕移向文哥，手指轻点一下屏幕，肩膀微沉，表情疑惑；文哥在旁自然坐姿；镜头不推近。
  • 镜头 2：文哥俯身凑近屏幕，手指缓慢指向 XML 映射区域，转头看向林可耐心讲解；林可侧头跟随；镜头固定。
  • 镜头 3：屏幕特写保持稳定；林可的手在画面边缘轻拍桌面一下，手指指向命名不一致的两行；镜头固定。
  • 镜头 4：林可双手离开键盘，抬头与文哥对视，露出轻松微笑；文哥微微点头；镜头固定，不推近。

一致性核对​

  • 镜头 1、2、4 中林可为同一张脸、同一发型、同一服装；文哥同样一致。
  • 双人位置、服装、场景基调跨帧一致，身份不互换。
  • 无多余人物、无漫画图形、无品牌 Logo 与真实名人。
