MyBatis 踩坑：为什么查不到数据？ · 剧本与分镜

双人互动写实竖屏动态漫验证小样。剧情按「冲突 → 求助 → 解决 → 收尾」四拍组织；双角色人设锁见 examples/manga-verify-mybatis/character-ref.json。

基本参数​

项值
画幅竖屏 9:16，720×1280，H.264 mp4 + AAC
分段4 段，每段 5 秒，硬切拼接，共 20.17s
首帧image_gen，seedream_5.0_pro，9:16
动态image_to_video，seedance_2.5，duration 5，ratio 9:16；片段静音
配音edge-tts 双角色：林可 zh-CN-XiaoxiaoNeural +6%；文哥 zh-CN-YunyangNeural +0%；后期混入，段内 0.6s 起
字幕ASS 硬字幕；Noto Sans CJK SC 32px，白字黑描边
后期本地 FFmpeg 拼接、配音对齐、字幕烧录；默认无 BGM

剧情结构​

  1. 冲突：林可写 MyBatis 查询，SQL 执行成功却查不到数据，皱眉求助旁边的文哥。
  2. 求助：文哥俯身一起看代码，提示核对数据库字段与实体类属性名是否对上。
  3. 解决：屏幕特写 XML 映射，发现下划线与驼峰命名不一致、未开启自动转换；林可恍然大悟。
  4. 收尾：林可改完配置，与文哥对视微笑；文哥补充 MyBatis-Plus 可一键开启驼峰转换。

一致性禁区​

  • 林可与文哥各自的脸部、发型、服装、肤色在所有镜头间保持不变；不新增其他人物。
  • 真人写实摄影风；不出现漫画式图形、夸张表情线、悬浮机器人实体。
  • 屏幕内容为真实编辑器 / 映射 XML 界面；正式剧集对应仓库真实源码片段。
  • 动作以自然转头、俯身、指屏、对视等互动为主；禁止纯静帧缓慢推镜。
  • 双人同框帧中两人身份、位置、服装不得互换或漂移。
