# EP01 · AI 绘图提示词

> 使用方法：每条提示词 = 全局画风基底（见 [../../config/character.json](../../config/character.json) 的 `style_base`）+ 下方分镜描述。生成后按同名放入 `assets/` 目录，替换 SVG 占位图。

## 全局基底

```text
扁平国漫科普漫剧，干净黑色线条，低饱和柔和配色，白底，画面简洁，文字少，人物比例正常无畸变，教学向场景，高清，适合网页展示
```

## 一致性检查清单

- [ ] 阿乐、文哥造型在 6 格中保持一致（发型、服装配色）；
- [ ] 每格背景风格统一，无写实阴影与复杂纹理；
- [ ] 画面内不放大段代码或长文字，台词由网页气泡承载；
- [ ] 人物手脚、五官正常，无畸变与多余手指。
