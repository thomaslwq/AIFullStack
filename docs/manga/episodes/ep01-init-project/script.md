## 分镜剧本

### 分镜 1 · 书桌前的困惑

- **画面**：阿乐对着一个空白文件夹挠头，电脑屏幕空空如也；文哥从画面侧边出现。
- **阿乐**：我想做一套前后端项目，不知道从哪里下手……
- **文哥**：别慌，我们一步一步从零搭建。

### 分镜 2 · 后端初始化

- **画面**：IDE 中的 Spring Initializr 界面，文哥指向屏幕。
- **文哥**：后端先用 Spring Boot，引入 Web、MyBatis、MySQL 依赖。
- **阿乐**：原来不是自己手写所有文件！

### 分镜 3 · AI 辅助开发

- **画面**：蓝色半透明 AI 助手悬浮在 IDE 侧边，输出代码片段。
- **文哥**：Cursor、Cloud Code 这类 AI 工具可以帮我们生成基础配置与实体类。
- **阿乐**：哇，AI 直接帮我写实体和样板代码？

### 分镜 4 · 前端初始化

- **画面**：VS Code 终端，命令行创建 Vite + React 项目。
- **文哥**：前端用 Vite 创建 React 项目，比老的脚手架更快。
- **阿乐**：前后端是分成两个项目存放吗？

### 分镜 5 · 联调坑点：跨域

- **画面**：浏览器控制台红色报错，阿乐一脸惊讶。
- **阿乐**：接口访问失败！这个跨域报错是什么？
- **文哥**：这是新手最高频的坑，后端加一段 CORS 跨域配置就能解决。

### 分镜 6 · 前后端打通

- **画面**：浏览器页面成功展示后端返回的数据，两人微笑。
- **文哥**：前后端打通！接下来我们学习 MyBatis 数据库操作。
- **阿乐**：期待下一集 MyBatis！
