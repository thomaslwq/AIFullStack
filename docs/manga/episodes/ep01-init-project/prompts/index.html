EP01 · AI 绘图提示词

使用方法：每条提示词 = 全局画风基底（见 ../../config/character.json 的 style_base）+ 下方分镜描述。生成后按同名放入 assets/ 目录，替换 SVG 占位图。

全局基底​

扁平国漫科普漫剧，干净黑色线条，低饱和柔和配色，白底，画面简洁，文字少，人物比例正常无畸变，教学向场景，高清，适合网页展示

分镜图​

01.jpg · 书桌前的困惑​

全局基底；短发少年阿乐穿休闲卫衣，坐在电脑前挠头，表情迷茫，电脑屏幕显示空白文件夹；画面侧边一位穿简约衬衫的沉稳工程师文哥刚出现；室内书桌场景，留白充足

02.jpg · 后端初始化​

全局基底；文哥指向电脑屏幕，屏幕显示 Spring Initializr 工程初始化界面，列出 Web、MyBatis、MySQL 依赖选项；阿乐在旁观察；编辑器风格画面

03.jpg · AI 辅助开发​

全局基底；蓝色半透明悬浮机器人 AI 助手位于 IDE 侧边，周围浮现代码片段气泡；文哥与阿乐看着屏幕；科技感柔和蓝光，不刺眼

04.jpg · 前端初始化​

全局基底；VS Code 界面与终端窗口，终端显示创建 Vite React 项目的命令行；文哥指向终端，阿乐点头；明亮简洁

05.jpg · 跨域报错​

全局基底；浏览器开发者控制台显示红色报错文字（CORS 字样），阿乐惊讶皱眉，文哥在旁准备解释；报错用抽象红色提示块表现，不堆砌真实代码

06.jpg · 前后端打通​

全局基底；浏览器页面成功展示后端返回的数据卡片，阿乐与文哥微笑竖起拇指；画面明亮积极，庆祝感但不过度装饰

card.jpg · 知识点卡片​

全局基底；一张圆角知识卡片，标题“本集核心要点”，四个图标条目：Spring Boot、React、AI 编码、CORS 跨域；版式规整，适合教学总结

一致性检查清单​

  • 阿乐、文哥造型在 6 格中保持一致（发型、服装配色）；
  • 每格背景风格统一，无写实阴影与复杂纹理；
  • 画面内不放大段代码或长文字，台词由网页气泡承载；
  • 人物手脚、五官正常，无畸变与多余手指。
