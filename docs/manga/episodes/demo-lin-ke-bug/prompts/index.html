Demo 首帧生图提示词

通用规则：每条 prompt 必须先拼接【人设锁前缀】，再写镜头场景；系列套图共享身份、发型、服装、配色。比例 9:16，写实真人。

人设锁前缀（每条 prompt 强制前置）​

写实真人摄影风格；主角林可（Linn），24 岁中国女生，青春精致轻熟，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；身穿白色修身衬衫、黑色高腰西装短裙、简约黑色低跟鞋；专业程序员气质，不浮夸；都市写实摄影，办公室柔和柔光，浅景深；脸部特征全程锁定，同一张脸，发型不变，服装不变，肤色一致。

全局画风后缀（每条 prompt 追加）​

竖屏 9:16，真实办公室场景，自然光与屏幕光，电影感浅景深，皮肤质感真实，避免动漫、避免卡通、避免塑料感；人物微表情与手部动作自然，避免僵硬静帧与单纯推镜。

镜头 1 · 加班发愁（0.0–5.0s）​

【人设锁前缀】傍晚偏暗的开放式办公室，林可独自坐在工位前，面对笔记本电脑，IDEA 编辑器屏幕显示 Java 代码与红色报错堆栈；她眉头轻皱，视线落在报错上，一只手停在键盘上，表情无奈发愁；桌面有半杯咖啡、便利贴、机械键盘；侧后方环境光偏暖，屏幕冷光映在她脸上。【全局画风后缀】

镜头 2 · AI 助手提示（5.0–10.0s）​

【人设锁前缀】同一工位，笔记本屏幕侧边悬浮一个半透明蓝色全息 AI 助手光效，旁边弹出发光的代码提示气泡，气泡内是一行判空代码；林可侧头看向 AI 提示，表情由发愁转为好奇，眼神专注；蓝色全息光柔和打在她侧脸。【全局画风后缀】

镜头 3 · 改代码专注（10.0–15.0s）​

【人设锁前缀】林可右手握鼠标，左手手指在键盘上快速敲下一行代码，表情专注认真，眉头微蹙后舒展；屏幕编辑器中新增一行蓝色判空代码；桌面键盘与代码细节清晰，她身体微微前倾。【全局画风后缀】

镜头 4 · 成功下班（15.0–20.0s）​

【人设锁前缀】IDEA 控制台打印绿色 success 与运行通过提示；林可靠在椅背上，微笑着轻轻伸懒腰，表情释然轻松，眼神明亮；窗外傍晚天色，办公室灯光柔和；桌上咖啡与便利贴，氛围收尾温暖。【全局画风后缀】

视频片段运动提示（图生视频，每段 5 秒）​

  • 镜头 1：林可视线在报错与键盘间移动，轻微叹气，肩膀微沉；镜头固定，避免推镜。
  • 镜头 2：全息 AI 气泡轻微浮动发光，林可侧头、眼神跟随提示；手部自然搭在鼠标上。
  • 镜头 3：手指敲击键盘的自然动作，鼠标点击，表情由蹙眉到舒展；代码行高亮出现。
  • 镜头 4：靠椅背、双手轻抬伸懒腰，微笑放松；控制台 success 保持绿色稳定。
