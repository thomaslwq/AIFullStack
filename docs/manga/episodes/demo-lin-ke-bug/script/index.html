Demo 样片剧本：AI 帮我改了一行代码，我准时下班了

通用 Skill ai-coding-manga-generator 的首个样片。人设锁、音色、分镜模板见 examples/manga-demo/character-ref.json。

基本参数​

项值
比例9:16 竖屏
分辨率720 × 1280
总时长20 秒（4 段 × 5 秒）
画面风格写实真人摄影，非漫画
配音林可专属音色（固定 edge-tts 女声），逐句对齐时间轴
字幕ASS 硬字幕，底部安全区，长句手动换行
BGM无（与 EP01 一致；后续剧集可按可选低音量科技轻音乐追加）

剧情结构（冲突 → 求助 → 解决 → 收尾）​

  1. 冲突：加班被一个 Bug 卡住，报错堆栈看不透，林可发愁。
  2. 求助：AI 助手悬浮给出判空提示，林可侧头看懂线索。
  3. 解决：补上一行 null 校验，表情由发愁转专注。
  4. 收尾：控制台打印 success，靠椅背微笑伸懒腰，准时下班。

分镜表​

镜号时间台词（配音 + 字幕）画面要点动作 / 表情
10.0–5.0s啊，这个 Bug 卡好久了。傍晚偏暗办公室，工位笔记本 IDEA 显示 Java 代码与红色报错堆栈；桌上咖啡、便利贴、机械键盘皱眉看报错，手停在键盘，无奈发愁；屏幕冷光映脸
25.0–10.0s试试判空，这里少了 null 校验。屏幕侧边悬浮半透明蓝色全息 AI 助手，弹出发光代码提示气泡（判空代码）侧头看向 AI 提示，表情由发愁转好奇，眼神专注；蓝光打侧脸
310.0–15.0s原来是这里漏了判断。编辑器新增一行蓝色判空代码；键盘与代码细节清晰右手握鼠标，左手手指快速敲一行，身体微前倾；眉头微蹙后舒展
415.0–20.0s搞定！今天可以准时下班啦。IDEA 控制台打印绿色 success；窗外傍晚，办公室灯光柔和靠椅背微笑轻伸懒腰，释然轻松，眼神明亮

一致性禁区​

  • 林可的脸、发型、衬衫、短裙、低跟鞋在 4 个镜头中必须完全一致，不换发色、不换服装、不换脸型。
  • 画面内不放大段文字；代码只保留简短判空片段，台词由配音与字幕承载。
  • 避免僵硬静帧、避免单纯缓慢推镜；优先手部动作、视线转移、表情变化等自然微动作。
  • 技术场景聚焦：IDE 编辑器、报错控制台、终端 success 提示、AI 代码提示气泡。
