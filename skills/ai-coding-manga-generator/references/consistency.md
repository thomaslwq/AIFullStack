# 角色锁与跨帧一致性规则

## 1. 人设前缀（强制前置）

每条生图 prompt 的**最前面**拼接完整人设锁，再写场景、动作、道具。人设卡存于 `examples/<slug>/character-ref.json`，跨集复用同一描述。

样例（林可，可替换为新主角）：

```text
24 岁中国女生，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；
白色修身衬衫，黑色高腰西装短裙，简约黑色低跟鞋；专业程序员气质，不浮夸；
都市写实摄影，办公室柔和柔光，浅景深；脸部特征全程锁定，同一张脸，发型不变，
服装不变，肤色一致。
```

- 人设前缀之后再接全局画风后缀（写实摄影、光线、景深、质感）。
- 每张帧独立写全 prompt；禁止用「同上」「与上图同一人物」省略身份描述。

## 2. 跨帧禁区

以下内容在同一集所有镜头、以及跨集之间不得变化：

- 脸部特征、脸型、眉眼、肤色；
- 发型、发色、发长；
- 服装、鞋、配饰；
- 场景基调（办公室、光线、桌面道具风格）。

同时禁止：

- 新增其他人物；
- 漫画式图形、夸张表情线、悬浮机器人实体；
- 更换镜头后人物年龄、体型、气质漂移；
- 出现真实名人、品牌 Logo 或可识别第三方肖像。

## 3. 动作与镜头规则

- 动态片段以自然表情与手部细节为主：呼吸、眨眼、转头、手势、肩部与上身微动。
- 禁止纯静帧缓慢推镜；镜头固定或平缓有目的，不抖动、不跳切。
- 视频 prompt 只写动作、表情、镜头；不写台词、配乐、人声、字幕、时长、比例、模型。

## 4. 屏幕内容规则

- 屏幕呈现真实编辑器、终端、控制台或浏览器界面；文字模糊可辨即可。
- 示意伪代码可用于样板演示；正式教程剧集应让屏幕内容对应仓库真实源码片段，避免与教程脱节。
- AI 助手以编辑器侧边面板或半透明全息光效呈现，不做违和的实体机器人。

## 5. 写实风关键词与避免项

- 推荐：都市写实摄影、办公室柔光、浅景深、真实皮肤与面料质感、自然采光、35mm 写实摄影、电影感竖屏。
- 避免：扁平插画、国漫 / 日漫线稿、二次元、夸张大眼、塑料皮肤、过强滤镜、卡通阴影。
