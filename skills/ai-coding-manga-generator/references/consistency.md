# 角色锁、场景连续性与跨帧一致性规则

## 1. 双角色人设前缀（强制前置）

每条生图 prompt 的**最前面**拼接对应角色的完整人设锁，再写场景、动作、道具。人设卡存于 `examples/<slug>/character-ref.json` 的 `characters` 数组，跨集复用同一描述。

样例（女主林可，可替换为新主角）：

```text
24 岁中国女生，鹅蛋脸、细长眉眼、淡妆、眼神灵动自信；长柔顺黑色直发披肩；
白色修身衬衫，黑色高腰西装短裙，简约黑色低跟鞋；专业程序员气质，不浮夸；
半写实插画造型；脸部特征全程锁定，同一张脸，发型不变，服装不变，肤色一致。
```

样例（男工程师文哥）：

```text
28 岁后端工程师，短发，细框眼镜，浅灰 Polo 衫，气质沉稳耐心；
半写实插画造型，同办公室光影；脸部特征全程锁定，同一张脸，发型不变，
服装不变，肤色一致。
```

- 双人同框图必须把两人的人设前缀都写全；角色半身小窗插画各自只写本人前缀。
- 人设前缀之后再接全局画风后缀（光线、景深、质感）。
- 每张图独立写全 prompt；禁止用「同上」「与上图同一人物」省略身份描述。

## 2. 跨帧 / 跨集禁区

以下内容在同一集所有镜头、以及跨集之间不得变化：

- 各角色脸部特征、脸型、眉眼、肤色；
- 发型、发色、发长；
- 服装、鞋、配饰；
- 场景基调（办公室、光线、桌面道具风格）。

同时禁止：

- 新增其他人物（除人设卡已登记角色外）；
- 更换镜头后人物年龄、体型、气质漂移；
- 出现真实名人、品牌 Logo 或可识别第三方肖像。

## 3. 场景连续性（防瞬移）

- 同一集固定在同一工位 / 同一开放办公区；不换房间、不跨场景跳切。
- 人物位置变化必须有动作依据：如同伴从侧面缓步走到工位旁、俯身凑近屏幕；禁止上一秒还在座位、下一秒出现在桌子另一侧。
- 机位固定或缓慢推镜；镜头之间用一致的人物朝向、桌面道具和光源方向衔接。
- 模式 V（AI 片段）每段都携带同一工位场景参考；段与段之间复用首段场景图，不另造新环境。

## 4. 动作与表情规则

- 允许的细微动作：眨眼、转头、点头、抬手指屏幕、视线交流、扶眼镜、身体微微前倾、托腮思考、轻敲键盘 / 鼠标、皱眉、微笑。
- 禁止：大幅度跑动、跳跃、夸张肢体交互、匀速机械摆头、人物抽搐感动作。
- 程序员场景动作幅度天然偏小；优先让表情（疑惑 → 专注 → 恍然 → 释然）和视线传递互动，而不是大动作。
- 视频 prompt（模式 V）只写动作、表情、镜头；不写台词、配乐、人声、字幕、时长、比例、模型。

## 5. 不开口规则（规避口型错位）

- 当前环境没有可用的唇形同步工具；角色**不做对口型说话**。
- 台词一律走旁白 TTS（双角色音色区分）+ ASS 硬字幕；画面里人物只做倾听、指向、点头、表情反馈，嘴部不承担发声职责。
- 生图 / 生视频 prompt 不要求人物张嘴说话、不画说话口型；对话关系靠视线、手势和字幕气泡体现。

## 6. 屏幕内容规则

- 代码、配置、日志、报错、终端界面**一律由本地 HTML + 无头浏览器截图渲染**，源码取自仓库真实片段；不交给生图 / 生视频模型画编辑器（模型生成的代码必然乱码、假屏幕）。
- 本地卡片脚本：`production/gen_cards.py`；动效定位 class 在卡片 HTML 里预先标好（`.hl`、`.kw`、`.note b` 等）。
- AI 助手（如剧集需要）以编辑器侧边面板或角落悬浮小弹窗呈现，不做违和的实体机器人；不抢主体代码画面。

## 7. 画风关键词与避免项（半写实插画漫剧基线）

- 推荐：半写实数字插画、轻漫画质感、干净流畅线稿、柔和扁平上色、电影感柔和光影、现代互联网办公室、竖屏漫画分镜构图、背景简洁虚化。
- 避免：写实摄影皮肤毛孔质感（与本基线不符时）、国漫 / 日漫夸张大眼、二次元线稿、塑料皮肤、过强滤镜、卡通阴影、悬浮机器人实体。
- 若某集改走真人写实风，须在人设卡 `style` 字段整体切换，并同步替换本节关键词；同一集内画风不混用。

## 8. 角色小窗与名牌（模式 L）

- 角色半身插画小窗：cover crop 取半身（竖向裁剪略偏上），滑入淡入 + 缓慢推镜，圆角 16px。
- 名牌用角色专属底色 + 对比色文字；基线：文哥蓝灰 `(122,162,247)` 白字；林可琥珀 `(229,192,123)` 深字 `(31,36,48)`。
- 小窗位置基线：`WIN_W=282, WIN_H=360, WIN_X=402, WIN_Y=600`（720×1280 画布）；构图遮挡主体时再微调，不在同一集内随意变换位置。
