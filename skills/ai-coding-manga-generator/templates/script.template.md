## 剧情结构

1. **冲突**：主角在教程对应的真实场景中卡住（报错、报错堆栈、需求受阻）。
2. **求助**：AI 助手给出提示（侧边面板 / 全息光效 + 代码气泡）。
3. **解决**：主角动手改对（补校验、改配置、跑通命令），表情由发愁转专注。
4. **收尾**：成功反馈（控制台 success、页面跑通），主角释然放松。

## 一致性禁区

- 主角脸部、发型、服装、肤色在所有镜头间保持不变；不新增人物。
- 真人写实摄影风；不出现漫画式图形、夸张表情线、悬浮机器人实体。
- 屏幕内容为真实编辑器 / 终端 / 浏览器界面；正式剧集对应仓库真实源码片段。
- 动作以自然表情与手部细节为主；禁止纯静帧缓慢推镜。
